# 🌟 Tribute Page – Dr. A. P. J. Abdul Kalam

A responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, created as part of the Veda Technology Web Development Internship – Task 1.

## 📌 About the Project

This project is a simple and responsive tribute page built using HTML5 and CSS3.

The page highlights the life, achievements, timeline, and legacy of Dr. A. P. J. Abdul Kalam.

## 🚀 Features

- Responsive design for desktop and mobile devices
- Semantic HTML5 structure
- Tribute image with caption
- Biography section
- Major achievements section
- Timeline section
- Legacy and inspiration section
- Responsive typography and layout
- Clean and readable UI

## 🛠️ Technologies Used

- HTML5
- CSS3
